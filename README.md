# AR Рулетка

Android-приложение для **реального измерения расстояния через камеру**. Точки закрепляются в физическом пространстве средствами Google ARCore, а расстояние вычисляется по их трёхмерным координатам.

## Возможности версии 1.0.0

- измерение между двумя реальными AR-точками;
- приоритет Depth API, когда он поддерживается телефоном;
- резервное измерение по обнаруженным плоскостям и feature points;
- видимая линия между точками при движении камеры;
- расстояние от камеры до поверхности под центральным прицелом;
- миллиметры, сантиметры, метры и дюймы;
- отмена последней точки и быстрое новое измерение;
- локальная история до 100 результатов;
- автоматическая проверка состояния AR-трекинга;
- Android 10 и новее;
- GitHub Actions: тесты, lint, debug APK, release APK и AAB;
- безопасная release-подпись через GitHub Secrets.

## Важно о точности

Это не симулятор. Приложение использует координаты ARCore в метрах. Итоговая погрешность зависит от телефона, освещения, текстуры поверхности, движения камеры и расстояния до объекта. Для точного строительного контроля приложение не заменяет поверенную лазерную рулетку.

Лучший результат получается при расстоянии примерно 0,5–5 метров, хорошем освещении и медленном перемещении телефона перед постановкой точек. Стекло, зеркало, блестящие, однотонные и очень тёмные поверхности распознаются хуже.

## Требования

- Android 10+;
- устройство с поддержкой Google ARCore;
- установленный компонент **Google Play Services for AR**;
- задняя камера;
- Depth API необязателен.

## Сборка на GitHub

1. Создайте пустой репозиторий GitHub.
2. Загрузите всё содержимое этой папки в корень репозитория.
3. Откройте вкладку **Actions**.
4. Запустите workflow **Android Build** через **Run workflow** либо сделайте push в `main`.
5. После завершения откройте запуск workflow и скачайте:
   - `AR-Roulette-debug-apk`;
   - `AR-Roulette-release`.

Workflow использует JDK 21, Gradle 8.13 и Android Gradle Plugin 8.13.2.

## Подписанный release APK/AAB

Создайте keystore локально:

```bash
keytool -genkeypair -v \
  -keystore ar-roulette-release.jks \
  -alias arroulette \
  -keyalg RSA \
  -keysize 4096 \
  -validity 10000
```

Закодируйте файл в Base64.

Linux:

```bash
base64 -w 0 ar-roulette-release.jks > keystore-base64.txt
```

PowerShell:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("ar-roulette-release.jks")) | Set-Content keystore-base64.txt
```

В GitHub откройте **Settings → Secrets and variables → Actions** и создайте четыре секрета:

| Secret | Значение |
|---|---|
| `KEYSTORE_BASE64` | содержимое `keystore-base64.txt` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | псевдоним ключа, например `arroulette` |
| `KEY_PASSWORD` | пароль ключа |

После этого release APK и AAB будут подписываться автоматически. При создании тега вида `v1.0.0` workflow также создаст GitHub Release и прикрепит подписанные файлы.

## Локальная сборка

Откройте проект в актуальной Android Studio и дождитесь синхронизации Gradle. Либо установите Gradle 8.13 и выполните:

```bash
gradle assembleDebug
```

APK появится в:

```text
app/build/outputs/apk/debug/
```

## Как пользоваться

1. Разрешите доступ к камере.
2. Медленно поводите телефоном из стороны в сторону, пока статус не покажет стабильное слежение.
3. Наведите центральный прицел на первую поверхность и нажмите **«Поставить точку 1»**.
4. Наведите прицел на вторую точку и нажмите **«Поставить точку 2»**.
5. Результат появится сверху и сохранится в истории.
6. После готового измерения кнопка **«Новое измерение»** сразу начинает следующую пару точек.

## Техническая реализация

- `ARSceneView` запускает и обслуживает сессию ARCore.
- В центре кадра выполняется реальный `Frame.hitTest()`.
- Подходящий `HitResult` превращается в `Anchor`.
- Расстояние вычисляется как евклидово расстояние между двумя 3D-позициями якорей.
- Позиции якорей проецируются матрицами ARCore обратно на экран, поэтому линия визуально остаётся на измеряемом объекте.
- Depth API включается только после проверки `Session.isDepthModeSupported()`.

## Конфиденциальность

Изображение с камеры используется только для локальной AR-сессии. Проект не содержит аналитики, рекламы, сетевой отправки кадров или разрешения на интернет.
