# AR Рулетка 1.3.0

Android-приложение для реального измерения расстояний через ARCore. Камера определяет 3D-точки пространства, приложение закрепляет AR-якоря и рассчитывает расстояние, высоту или площадь в реальном масштабе.

## Возможности

- адаптивный тёмный интерфейс в стиле профессиональной AR-рулетки;
- отдельные разметки для книжной и альбомной ориентации;
- переключение ориентации без сброса поставленных AR-точек;
- режимы «Точка», «Рулетка», «Площадь», «Высота» и «До объекта»;
- измерение площади по четырём точкам контура;
- миллиметры, сантиметры, метры и дюймы;
- история последних 100 результатов;
- сохранение снимка экрана с нанесённым измерением в `Pictures/AR Рулетка`;
- экранная сетка;
- Android 10 и новее;
- GitHub Actions для unit-тестов, lint, debug APK, release APK и AAB.

## Стабилизация и точность

Версия 1.3.0 использует несколько уровней защиты от дрожания:

1. На поддерживаемых устройствах включается ARCore Electronic Image Stabilization (EIS).
2. Скорость перемещения и вращения телефона рассчитывается по позе камеры; кнопка точки разблокируется только после непрерывного устойчивого положения.
3. Цель проверяется серией кадров, медианной кластеризацией и гистерезисом, поэтому мелкая дрожь не сбрасывает уже найденную поверхность.
4. В обычном кадровом цикле используется до трёх hit-test лучей, а при окончательной установке точки — до пяти лучей для более точного выбора поверхности.
5. Depth hit-test имеет приоритет на совместимых устройствах, а Raw Depth и карта confidence периодически проверяют центральную область прицела.
6. AR-якорь создаётся из текущего проверенного HitResult, а не из усреднённых координат разных кадров.
7. Итоговое значение рассчитывается по серии кадров с медианной фильтрацией и отбрасыванием выбросов.

На устройствах без Depth API используются распознанные плоскости и характерные точки ARCore. Приложение не является поверенным измерительным прибором.

## Защита от перегрева

- выбирается 30 FPS camera config, ближайший к 1280×720, вместо максимального разрешения SceneView;
- используется `RenderQuality.Performance`, отключены расчёт освещения, источники света сцены и визуализация плоскостей;
- прикладной AR-анализ ограничен примерно 10 кадрами/с и автоматически снижается примерно до 7/4/2,5 кадров/с при росте тепловой нагрузки;
- во время быстрого движения пропускаются бесполезные hit-test лучи;
- Raw Depth обычно читается не чаще одного раза за 750 мс и ещё реже при нагреве;
- Android Thermal Status и Thermal Headroom контролируются во время работы;
- при критическом тепловом состоянии AR-камера закрывается до охлаждения телефона.

Не используйте приложение во время зарядки. Если корпус становится очень горячим, немедленно прекратите измерение, снимите чехол и дайте телефону полностью остыть.

## Как измерять

1. Медленно перемещайте телефон, пока приложение не распознает пространство.
2. Наведите прицел на нужную поверхность.
3. Остановите движение и удерживайте телефон, пока прицел не станет белым и статус не покажет хорошее качество.
4. Поставьте необходимые точки. При быстром движении кнопка временно блокируется, чтобы не закрепить случайную точку.
5. После последней точки кратко удерживайте телефон неподвижно — результат будет уточнён и сохранён.

Для площади ставьте четыре точки последовательно по контуру. Для высоты начинайте с нижней точки. Лучшие условия: хорошее освещение, матовая фактурная поверхность и расстояние до 5–8 метров.

## Сборка на GitHub

1. Загрузите содержимое этой папки в корень GitHub-репозитория.
2. Откройте вкладку **Actions**.
3. Запустите workflow **Android Build** или отправьте commit в `main`/`master`.
4. Готовые файлы появятся в артефактах:
   - `AR-Roulette-debug-apk`;
   - `AR-Roulette-release`;
   - `AR-Roulette-lint-reports`.

## Release-подпись

Добавьте в GitHub Secrets:

- `KEYSTORE_BASE64` — keystore в Base64;
- `KEYSTORE_PASSWORD`;
- `KEY_ALIAS`;
- `KEY_PASSWORD`.

Без секретов release-файлы собираются с конфигурацией проекта, но не получают пользовательскую release-подпись. При push тега `v*` workflow создаёт GitHub Release только при наличии keystore.
